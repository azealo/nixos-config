# Azealo's NixOS Configuration
This NixOS configuration is made for Lenovo IdeaPad L3 15IML05.

![GitHub License](https://img.shields.io/github/license/azealo/nixos-config?logo=unlicense&logoColor=white&color=purple)
![GitHub last commit](https://img.shields.io/github/last-commit/azealo/nixos-config?color=green&logo=github)




### Main Features
- KDE Plasma with plasma-manager configuration
- Zapret DPI Bypass if you are forced to live bad government
- Nvidia PRIME with proprietary drivers
- Plymouth boot animation
- zsh shell with Oh My Zsh, powerlevel10k, zoxide and fzf
- Includes lot of stuff for gaming, music production and coding
- horrible home-manager organisation
- free
